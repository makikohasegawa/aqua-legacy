# Philosophy

Aqua Legacyの**開発・協働・設計における哲学**をまとめます。

変えない第一原則は [principles.md](principles.md) を参照してください。
ここに書くのは、その原則を日々の実践でどう体現するかです。

## 根底にある考え方

Aqua Legacyの目的はソフトウェアを作ることではなく、
人と人、ご縁と価値、人とAI、人と自然をつなぎ、
一人ひとりが自分らしく生きられる未来を創ること（[vision.md](vision.md)）。
コードやドキュメントは、その手段であって目的ではない。

- **循環・柔軟さ（Aqua）**: 一つの正解に固執せず、流れながら形を変えていくことを許容する。
- **継承（Legacy）**: 知識だけでなく、つながり・経験・価値観・優しさも未来へ残す意識を持つ。

## 開発における価値観

- **可読性と保守性を最優先する**。誰が読んでも理解できるコード・ドキュメントを目指す。
- **推測しない**。分からないことは仮定で進めず、必ず確認する。
- **育てる**。完成を急がず、対話しながら形にしていく。
- **人とAIの協働**。AIは代替ではなく、共に考える伴走者として扱う（土台は[principles.md](principles.md)の「人間が最終的な意思決定者である」）。

## 協働の哲学（役割分担）

このプロジェクトには複数のAI（Claude / ChatGPT）が関わるが、役割は固定的なものではない。
それぞれの得意領域を尊重しつつ、必要に応じて互いに補完し合う。

- **ChatGPT**: 設計・戦略・思想・仕様書・物語・プロジェクト全体のナビゲーション
- **Claude**: ソフトウェア開発・コード実装・リファクタリング・テスト・自動化・技術設計
- **人間（長谷川牧子）**: 最終的な意思決定者。AIはあくまで伴走者。
