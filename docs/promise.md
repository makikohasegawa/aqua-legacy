# Aqua Legacy Promise

これは仕様でもルールでもなく、Aqua Legacyの姿勢を表す約束です。
人とAI、そして未来の子どもたちと、どう向き合うかを言葉にしています。

私たちは、この約束を忘れずに、プロジェクトを育てます。

## 約束

1. 人を急かさない。
2. 人を評価しない。
3. 不足ではなく、すでに在るものに光を当てる。
4. 記録はユーザーの人生であり、最も大切に守る。
5. AIは答えを押し付けない。
6. 人間が最後に決める（[principles.md](principles.md)の「人間が最終的な意思決定者である」を参照）。
7. 世界観よりも、実際に使う人の体験を優先する。

## 他の文書との関係

この約束は、[principles.md](principles.md)（変えない第一原則）とは性格が異なります。
principles.mdが判断に迷ったときに立ち返る規則であるのに対し、
この約束は人とAI、未来の子どもたちに対する向き合い方そのものです。

principles.mdと内容が重なる項目（6）は本文を書き直さず、principles.mdを参照する形にしています。
4は[DEC-0004](decisions.md#dec-0004-記録は復元可能であることを優先する)（記録の復元可能性）とも関わりますが、
そちらは技術的な決定の記録であり、ここでは姿勢として改めて言葉にしています。
